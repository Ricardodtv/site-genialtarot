GENIAL TAROT — VERSÃO CLOUDFLARE + TELEGRAM
============================================

Como funciona a partir de agora:
- O GITHUB guarda os ficheiros (continuas a fazer upload lá, como sempre).
- A CLOUDFLARE liga-se ao GitHub e publica o site automaticamente
  a cada alteração — e envia os avisos para o teu TELEGRAM.

FICHEIROS
---------
index.html          → site principal
tarot-gratis.html   → jogo "Tarot Grátis"
_worker.js          → NOVO: a "ponte" que envia avisos ao Telegram
profile.png, tudo-aqui.png, mestre-alberto.jpg → imagens
mystic-ambient.mp3, ambient.mp3 → músicas
favicon.ico, og-image.png, robots.txt, CNAME → apoio

PASSO 1 — ATUALIZAR O GITHUB
----------------------------
1. Repositório site-genialtarot → "Add file" → "Upload files".
2. Envia TODOS os ficheiros desta pasta (substitui os antigos).
3. "Commit changes".

PASSO 2 — CRIAR A CONTA CLOUDFLARE E LIGAR AO GITHUB
----------------------------------------------------
1. Vai a dash.cloudflare.com → "Sign up" (só email e password).
2. No menu lateral: "Workers & Pages" (ou "Compute (Workers)").
3. "Create" → separador "Pages" → "Connect to Git" (ou "Import an
   existing Git repository").
4. Autoriza o GitHub quando ele pedir e escolhe o repositório
   site-genialtarot.
5. Nas definições de build: Framework preset = None; Build command =
   (vazio); Build output directory = / (barra). → "Save and Deploy".
6. No fim aparece o endereço do site, algo como:
   https://site-genialtarot.pages.dev

PASSO 3 — GUARDAR OS SEGREDOS DO TELEGRAM
-----------------------------------------
1. Ainda na Cloudflare, abre o teu projeto → "Settings" →
   "Variables and Secrets" (ou "Environment variables").
2. Adiciona DUAS variáveis (tipo: Secret), em "Production":
   Nome: TELEGRAM_BOT_TOKEN   Valor: o token do teu bot
   Nome: TELEGRAM_CHAT_ID     Valor: o teu chat id
3. Grava e volta ao separador "Deployments" → botão "Retry deployment"
   (ou faz qualquer alteração no GitHub) para o site recarregar os segredos.

COMO DESCOBRIR O TOKEN E O CHAT ID
----------------------------------
- Token do bot: no Telegram, fala com @BotFather → /mybots →
  escolhe o teu bot → "API Token". (Se já usas o bot noutro sítio,
  usa o token que já tens guardado.)
- Chat ID: no Telegram, fala com @userinfobot — ele responde com o
  teu "Id" (um número). É esse.

TESTE FINAL
-----------
Abre https://site-genialtarot.pages.dev/tarot-gratis.html,
faz uma leitura de teste — deves receber o veredito no Telegram. 📲
